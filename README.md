## 🚀 Getting Started

### Prerequisites

- Modern Web Browser (Chrome, Edge, Firefox, Safari)
- Git (for version control)
- Optional: VS Code Live Server extension, Python `http.server`, or Node `serve`

### Local Development

1. **Clone the repository:**
   ```bash
   git clone https://github.com/syedmuhammadsaim/SAIM-PORTFOLIO.git
   cd SAIM-PORTFOLIO
   ```

2. **Serve locally:**
   - Using Python:
     ```bash
     python -m http.server 5500
     ```
   - Using VS Code: Right-click `index.html` and click **"Open with Live Server"**.
   - Or simply open `index.html` in your browser.

3. **Navigate to:**
   ```
   http://localhost:5500
   ```

## 🌐 Deployment (GitHub Pages)

This static portfolio can be published directly to GitHub Pages:

1. Push all code to the `main` branch:
   ```bash
   git push origin main
   ```
2. Navigate to your repository on GitHub: **Settings** > **Pages**.
3. Under **Build and deployment**, set Source to **Deploy from a branch**.
4. Select the `main` branch and `/ (root)` folder, then click **Save**.
5. Your portfolio will be live at `https://syedmuhammadsaim.github.io/SAIM-PORTFOLIO/`.
